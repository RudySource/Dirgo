# Dirgo 0.1.3

Dirgo 0.1.3 is a security and reliability patch for the local-first fuzzy
directory navigator for Zsh, Bash, and Fish.

Release commit: `dd7497d`. Protected CI run `32679864525` and release workflow
`32680020828` passed. All four public archive hashes were independently verified;
the macOS ARM64 and Intel binaries and the Linux amd64 binary on Debian 12 were
executed successfully. The maintained Homebrew tap passed strict audit, upgrade,
and formula tests.

## Highlights

- Human-facing TUI, fallback, bookmark, diagnostic, and error output escapes
  terminal controls and bidirectional overrides from untrusted filenames.
- The selected path remains byte-for-byte unchanged for navigation and is
  represented safely by JSON for machine consumers.
- Navigation history, per-shell transitions, and abandoned session records now
  have explicit bounded-retention policies.
- Concurrent navigation updates and competing bookmark renames are serialized in
  single write transactions, preventing lost visits and collision overwrites.
- `dgo doctor` diagnoses malformed configuration, while `dgo config path` and
  `dgo support` remain available in a broken environment.
- Top-level and nested help now explain every public workflow.
- README onboarding covers persistent shell setup, picker keys, supported
  platforms, troubleshooting, uninstall, and contributor verification.

## Install from an archive

1. Download the archive for your platform and `SHA256SUMS` from this release.
2. Run `sha256sum --check SHA256SUMS` on Linux, `shasum -a 256 -c SHA256SUMS`
   on macOS, or `Get-FileHash -Algorithm SHA256` on Windows.
3. Extract `dgo` (`dgo.exe` on Windows) into a directory on `PATH`.
4. Load the matching wrapper shown in the README, then run `dgo doctor` and
   `dgo refresh`.

## Compatibility

- The state schema remains version 1. Existing sessions without retention
  timestamps deserialize with a safe default and are migrated opportunistically.
- Linux binaries are built on Ubuntu 22.04 and reject any required glibc symbol
  newer than 2.35.
- Parent-shell navigation is supported for Zsh, Bash, and Fish. Windows provides
  the native CLI/TUI and actions but not a PowerShell or cmd wrapper in 0.1.x.
