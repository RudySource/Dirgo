# Dirgo 0.1.2

Dirgo is a local-first fuzzy directory navigator for Zsh, Bash, and Fish. It
indexes directories you have not visited yet, then uses bookmarks and local
navigation history to improve ranking without telemetry or network access.

## Fixed since 0.1.1

- The x86_64 Linux GNU archive is built on Ubuntu 22.04 and gated to require no
  symbol newer than glibc 2.35. The superseded 0.1.1 Linux archive required
  glibc 2.39 and did not run on Debian 12.

## Highlights

- Fast Rust CLI and responsive Ratatui picker with background Nucleo matching.
- Atomic, rebuildable redb filesystem index separated from persistent bookmarks,
  visits, and shell-session history.
- Safe shell wrappers with direct-path fast paths and no filesystem path `eval`.
- Conservative resolution: ambiguous and fuzzy destinations remain interactive.
- Zsh, Bash, and Fish integration; macOS, Linux, and Windows native binaries.
- Patched dependency graph and native operating-system release gates.

## Install from an archive

1. Download the archive for your platform and `SHA256SUMS` from this release.
2. Run `sha256sum --check SHA256SUMS` on Linux, `shasum -a 256 -c SHA256SUMS`
   on macOS, or `Get-FileHash -Algorithm SHA256` on Windows.
3. Extract `dgo` (`dgo.exe` on Windows) into a directory on `PATH`.
4. Load the matching wrapper shown in the README, then run `dgo doctor` and
   `dgo refresh`.

## Verification

The tagged workflow builds and tests four native targets before publishing any
asset: Apple Silicon macOS, Intel macOS, x86_64 Linux, and x86_64 Windows MSVC.
The Linux build also enforces a glibc 2.35 maximum symbol baseline. The release
includes aggregate SHA-256 checksums.

## Known limitations

- Parent-shell navigation integrations are provided for Zsh, Bash, and Fish;
  native PowerShell and cmd wrappers are not included in 0.1.2.
- Indexed navigation supports UTF-8 paths. Unix paths containing non-UTF-8 bytes
  or newlines cannot cross the text command-substitution boundary; a direct path
  handled by the shell wrapper remains native.

Report vulnerabilities through GitHub private vulnerability reporting. Remove
personal paths from ordinary issue logs and screenshots before submitting them.
